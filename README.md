# 注意力切换记录软件

当前主程序是一个 macOS 顶栏常驻工具，不再走旧的 Python 窗口入口。

运行入口有两个：

- 直接打开打包后的 `状态切换工具.app`
- 或在项目目录执行 `swift run`

启动后不会出现传统窗口。入口在系统 topbar 的彩色圆环图标，另有每块屏幕右侧中部的悬浮浮标，鼠标靠近会展开面板。

主界面现在只保留按钮、当前状态、持续时间。点击按钮后才展开标签选择。标签管理、提醒、自动 App 绑定、颜色和导出都在设置页。

`V2.1.0` 增加了轻量自动识别、超时提醒和可视化 App 绑定。设置页 `Auto` 中可把右侧运行 App 拖到左侧标签上完成绑定；系统只监听 macOS 前台 App 切换，命中规则并稳定一段时间后才会自动记录，不做截图、录屏或 OCR。
