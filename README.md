# 注意力切换记录软件

当前主程序是一个 macOS 顶栏常驻工具，不再走旧的 Python 窗口入口。

运行入口有两个：

- 直接打开打包后的 `状态切换工具.app`
- 或在项目目录执行 `swift run`

启动后不会出现传统窗口。入口在系统 topbar 的彩色圆环图标，另有每块屏幕右侧中部的悬浮浮标，鼠标靠近会展开面板。

主界面现在只保留按钮、当前状态、持续时间。点击按钮后才展开标签选择。今日看板、标签管理、提醒、自动 App 绑定、颜色和导出都在设置页。

`test 2.3.0` 增加了 Auto 切换反馈、悬浮浮标倒计时、导出圆形按钮、App 显示名缓存和打包签名修复。当前设置页 `Board` 展示今日状态统计、状态占比、时间河流和 Auto App 归因排行；设置页 `Auto` 中可把右侧运行 App 拖到左侧标签上完成绑定。系统只监听 macOS 前台 App 切换，命中规则并稳定一段时间后才会自动记录，不做截图、录屏或 OCR。

隐私边界：

- 不采集截图、录屏、窗口内容、键盘输入或剪贴板内容
- Auto 只读取 macOS 前台 App 名称、Bundle ID 和运行 App 列表
- 本地记录、导出文件、个人标签和设置都保存在 `data/`
- `data/`、构建缓存、发布包和归档目录已在 `.gitignore` 中排除，不进入 GitHub
